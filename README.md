# Delhi Metro LiveTrack UI

A modern reimagining of the Delhi Metro route map that transforms the traditional static DMRC network diagram into a real-time, interactive transit experience.

## Overview

Current metro maps are excellent for route reference but provide limited real-time context. Passengers can see stations and connections, yet they cannot easily visualize train movement, journey progress, remaining distance, or arrival estimates.

**Delhi Metro LiveTrack UI** bridges this gap by introducing a visually engaging metro dashboard that combines route visualization with live journey analytics.

## Features

* Real-time train position tracking along the metro line
* Dynamic station highlighting and journey progress visualization
* Live ETA calculations for upcoming stations
* Remaining distance estimation throughout the trip
* Interactive route simulation engine
* Journey progress indicators and segment-based tracking
* Bilingual station support (English & Hindi)
* Interchange station identification
* Modern cyber-inspired UI replacing conventional grey transit maps
* Responsive design for desktop and mobile devices

## Why It Matters

Traditional DMRC maps answer **"Where am I?"**

LiveTrack answers:

* **Where is the train right now?**
* **How much distance is left?**
* **How long until the next station?**
* **What is my total journey progress?**
* **Which interchange is approaching?**

By converting static route diagrams into an interactive real-time transit interface, this project improves passenger awareness, engagement, and travel planning while demonstrating how modern UI/UX can enhance public transportation systems.

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Real-time animation engine
* Responsive UI design

### Future Scope
Integration with live DMRC APIs, GPS-based train tracking, crowd-density analytics, and predictive arrival modeling.
